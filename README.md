# Delethos

**Delegate code. Demand proof.**

Delethos is a local-first, vendor-neutral control plane for verified delegation across coding agents.

The project is currently in governed founding design. Product implementation is not yet authorized; the founding specification will define the architecture, evidence contract, security boundary, adapter model, verification discipline, and execution roadmap before code lands.

> Coding agents should not be the sole final reviewers of their own work.

## Founding objective

Build an open control plane that can route a bounded engineering task to an appropriate coding agent, isolate execution, run deterministic checks, require independent review for material changes, and return a proof-carrying patch for a human to accept or reject.
